Dev Blog: Enterprise Home Lab

Project Status: Active

Phase 1: Physical Build & Hypervisor Deployment

  • Hardware Assembly & POST: Benchmark components outside the case to ensure stability, particularly monitoring the repurposed RTX 3070 Ti.
  • BIOS Configuration: Flash the Biostar B550MH to the latest stable firmware; enable AMD-V (SVM Mode) and IOMMU for essential virtualization mapping.
  • Proxmox VE Installation: Deploy the bare-metal OS cleanly to the 1TB NVMe SSD and establish root environment variables.

Phase 2: Storage Architecture & Network Segmentation

  • Storage Provisioning: Map the 1TB NVMe drive for performance-focused VMs and container roots; provision the 2TB 7200RPM HDD for data arrays, automated snapshots, and image ISO storage layers.
  • Virtual Networking: Establish stable default Linux Bridges (`vmbr0`) and map out future isolated VLAN topologies to isolate laboratory tests from household internet traffic.

Phase 3: Core Infrastructure & Identity Management

  • Lightweight Network Services: Spin up responsive Linux Containers (LXC) to host Pi-hole or local DNS/Ad-blocking setups, maximizing efficiency on the tight 16GB RAM overhead.
  • Identity Sandbox (Active Directory): Spin up a dedicated Windows Server VM environment acting as a primary Domain Controller to master group policy mechanics, organizational layouts, and secure access management routines.

Phase 4: Hardware Pass-Through & Security Hardening

  • GPU Isolation (NVENC): Configure system boot flags to isolate hardware devices via IOMMU tables, passing the GPU structure straight to rendering workloads.
  • Security Monitoring & Access Control: Strip back default root credential exposures over SSH in preference for unique hardware security keys, deploying local endpoint analytics to parse log events.

Welcome to my development log for my personal home lab. I created this space to document my technical journey, troubleshooting steps, and configurations as I build this environment from bare metal up.

Update Logs

June 10, 2026

Hardware Procurement Complete & Procurement Checklist Cleared: Finalized the hardware acquisition phase today with the purchase of the remaining core components. Upgraded the CPU choice from a Ryzen 5 3600 to a Ryzen 5 5600, providing a stronger Zen 3 architecture foundation for multi-threaded virtualization tasks. Also secured a 1TB NVMe SSD for high-speed OS/VM provisioning and a 2TB 7200RPM SATA HDD for high-capacity media and backup storage. Scavenged a functional spare chassis fan to complete the cooling configuration. The build is officially ready for physical assembly.

May 28, 2026

Hardware Pivot & Lifecycle Extension: Repurposing an NVIDIA RTX 3070 Ti for the server build. The card began exhibiting instability under heavy 3D rendering loads in a primary workstation. However, by aggressively undervolting and power-limiting the card, it will remain perfectly stable for hardware media transcoding. This works because media encoding relies entirely on the dedicated NVENC silicon rather than raw CUDA compute power, extending the usable life of the hardware.

May 28, 2026

Architecture Decision - Proxmox VE: Evaluated bare-metal hypervisor options for the host OS. Selected Proxmox VE (built on Debian Linux) over VMware ESXi due to licensing changes and hardware compatibility constraints with consumer-grade motherboards. Proxmox will allow for an efficient resource footprint using lightweight Linux Containers (LXC) for services like Pi-hole, maximizing the utility of the lab's 16GB RAM budget while providing native support for PCIe pass-through of the RTX 3070 Ti.
